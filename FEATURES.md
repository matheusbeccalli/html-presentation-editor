# FEATURES — phase checklist

Source of truth: `SPEC.md`. Section 2 (self-contained, offline, vendored code) overrides everything.
Build phases in order. Do not start a phase until the previous one works end to end.
An item is ticked only after it is built **and** tested, and `python build.py` passes its offline check.

Legend: `- [ ]` not done · `- [x]` done and tested.

---

## Phase 2: Select, move, resize, autosave

- [x] Click to select; selection box with 8 resize handles drawn in the overlay layer
- [x] Drag to move; Shift while resizing keeps the aspect ratio *(snapping, and Alt to turn it off, moved to Phase 7 by decision)*
- [ ] Arrow keys nudge 1 px, Shift+arrow 10 px
- [ ] Delete removes the selected element
- [ ] Ctrl+C / Ctrl+X / Ctrl+V / Ctrl+D (duplicate), also across slides
- [ ] Bring forward / send backward / bring to front / send to back
- [ ] Format pane "Size & position": X, Y, W, H in px, editable
- [ ] Right-click context menu with the common actions
- [ ] Canvas zoom: Ctrl+mouse wheel and zoom slider, 50–400%
- [ ] AutoSave layer 1 (6.1): on/off toggle in the title bar, turns on after the first manual save in the session
- [ ] AutoSave timing: 5 s after the last change, at most every 30 s while editing; never during drag, resize or IME composition
- [ ] AutoSave writes through `createWritable()` (atomic replace on close)
- [ ] AutoSave conflict check: compare `lastModified`; if changed on disk, pause and ask overwrite / save as copy / reload
- [ ] "Revert to version opened" (original kept for the session)
- [ ] Crash-recovery drafts in IndexedDB (6.2): snapshot full deck HTML every 30 s while unsaved, keep the last 5 per deck
- [ ] Stable deck id `<meta name="deck-id">`, created on first save
- [ ] On startup / open: recovery dialog ("Unsaved changes from 27/10 14:32 were found") with slide-1 thumbnail and Recover / Compare / Discard
- [ ] Drafts deleted after a successful save; all drafts purged after 7 days (setting: 1–30 days)
- [ ] File handles stored in IndexedDB for a "Recent files" list
- [ ] Privacy settings (6.3): "Keep recovery drafts in this browser" on/off, retention days, "Delete all drafts now", explanatory note
- [ ] IndexedDB unavailable → "Recovery unavailable" in the status bar, editor keeps working (every storage call in try/catch)
- [ ] Status indicator (6.4): Saved · Saving… · Unsaved changes · AutoSave off · Draft saved 14:32 · Recovery unavailable
- [ ] **Done when:** any element can be moved and resized precisely, every action undoes, and killing the browser mid-edit loses at most 30 seconds of work. Autosave (section 6): (1) with AutoSave on, closing the tab after an edit and reopening the file shows the edit; (2) with AutoSave off, killing the browser mid-edit and reopening offers to recover changes no older than 30 seconds; (3) "Delete all drafts now" leaves nothing in IndexedDB (DevTools > Application).

## Phase 6: Charts (section 5)

- [ ] Chart element stores JSON (`<script type="application/json" class="chart-data">`) plus a static SVG rendering
- [ ] Pure renderer `App.charts.render(json, width, height)` → SVG string; deterministic
- [ ] Priority 1 types: clustered column, stacked column, horizontal bar, line, combo (columns + line on secondary axis), waterfall, donut / pie
- [ ] Priority 2 types: 100% stacked column / stacked bar, scatter / bubble, area
- [ ] Resizing re-renders at the new size (never stretches the SVG)
- [ ] "Nice" axis ticks; label collision handling (shrink, rotate or skip category labels)
- [ ] Data editor: double-click opens a data grid in the Format pane (rows = categories, columns = series)
- [ ] Data editor: paste from Excel into the grid; add/remove rows and series; reorder by dragging
- [ ] Per series: name, color, chart type and axis (primary/secondary) for combo charts
- [ ] Per category: mark as estimate/projection (lighter fill or hatching, optional "E" suffix)
- [ ] Waterfall row roles: start, increase/decrease, subtotal, end; automatic (configurable) positive/negative colors; connector lines
- [ ] Live preview; every edit undoable
- [ ] Formatting: title, axis titles, legend (top/bottom/right/hidden), gridlines on/off, axis min/max (auto by default), gap width
- [ ] Data labels: on/off, position (inside end, outside end, center), number format (decimals, pt-BR/en-US separators, percent, negatives in parentheses, units text)
- [ ] Colors default to theme variables plus a derived palette; fonts from `--font-body`
- [ ] Annotations: automatic CAGR arrow between two columns; source/footnote line
- [ ] Unit tests for the renderer with fixed inputs
- [ ] Fallback documented: unsupported chart types pasted from Excel as images (Phase 5)
- [ ] **Done when:** an EBITDA bridge and a revenue-plus-margin combo chart can be built from data pasted from Excel, edited, saved, reopened, and printed to PDF with sharp lines.

## Phase 8: Present and export (section 7)

- [ ] Slideshow: F5 from first slide, Shift+F5 from current; Fullscreen API; scaled to fit with black letterboxing
- [ ] Slideshow navigation: arrows / Space / PageUp / PageDown / click; number + Enter to jump; B black screen; Esc exits; hidden slides skipped; comments never shown
- [ ] Presenter view (`window.open`): current slide, next slide, notes, elapsed timer, clock, synced via `postMessage`; explain how to allow pop-ups if blocked
- [ ] PDF: `window.print()` with `@page { size: 13.333in 7.5in; margin: 0 }`, one slide per page, `print-color-adjust: exact`
- [ ] PDF options: all slides, current slide, or range; include/exclude hidden slides; comments and editor UI never print
- [ ] One-line "Save as PDF" hint the first time
- [ ] PNG export of current or all slides at 2× with vendored html2canvas (MIT)
- [ ] "Copy slide as image" to clipboard (fallback: download PNG)
- [ ] All slides as ZIP via JSZip (reuse PptxGenJS's bundled copy if present, else vendor separately)
- [ ] PPTX export with vendored PptxGenJS (MIT): 13.333 × 7.5 in, `inches = px / 96`
- [ ] PPTX mapping: text (runs, bullets, indents, alignment), images (crop applied), tables (merged cells, fills, borders, alignment), shapes, native charts from chart JSON, waterfall as stacked column with invisible base (or image), speaker notes, unsupported items rasterized
- [ ] Post-export report listing anything rasterized or simplified
- [ ] "Save a clean copy": Save As with comments removed, hidden slides optionally removed, drafts untouched
- [ ] **Done when:** a 10-slide deck with text, a table, an image, a combo chart and a waterfall exports to a PDF that matches the screen, and to a PPTX where text, tables and the combo chart are editable in PowerPoint.
